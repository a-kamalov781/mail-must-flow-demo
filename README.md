# Почта не спит / Mail Must Flow — demo

A browser demo about automating a small post office. Sort letters, buy a robot, and write a program for it using a small Python-like language.

- Desktop keyboard and mouse.
- Russian and English interface.
- Progress is stored locally in the current browser.
- Build: `v15.5.0-public-demo2`.

The game is contained in `index.html`; no external assets or build step are required. `.nojekyll` keeps GitHub Pages from applying Jekyll processing.

This is an early demo for player feedback. The code was created and edited with AI assistance.

## По-русски

Браузерная демоверсия игры про автоматизацию маленького почтового отделения. Сортируйте письма, купите робота и напишите для него программу. Управление — клавиатура и мышь. Интерфейс — русский и английский; прогресс хранится в текущем браузере.
